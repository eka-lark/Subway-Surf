# 🎮 Endless Runner Game

A fast-paced endless runner mobile game inspired by Subway Surfers, designed with engaging gameplay mechanics, procedural track generation, power-up systems, and scalable architecture.

---

# 🚀 Features

* Infinite endless runner gameplay
* 3-lane movement system
* Dynamic obstacle generation
* Coin collection and reward system
* Power-ups (Jetpack, Magnet, Hoverboard, etc.)
* Increasing difficulty and speed progression
* Character and skin customization
* Daily missions and achievements
* Monetization-ready architecture
* Mobile-optimized controls and performance

---

# 🕹️ Gameplay Mechanics

## Controls

* Swipe Left → Move Left
* Swipe Right → Move Right
* Swipe Up → Jump
* Swipe Down → Slide
* Double Tap → Activate Hoverboard (Optional)

## Core Loop

1. Start running
2. Collect coins
3. Avoid obstacles
4. Increase speed over time
5. Crash → Game Over
6. Earn rewards and restart

---

# 💰 Economy System

## Coins

Used for:

* Character unlocks
* Power-up upgrades
* Cosmetic purchases

## Keys

Used for:

* Revive after crash
* Unlock premium rewards

# ⚡ Power-Ups

| Power-Up       | Function                   |
| -------------- | -------------------------- |
| Jetpack        | Fly and auto collect coins |
| Magnet         | Attract nearby coins       |
| Super Sneakers | High jump ability          |
| 2x Multiplier  | Double score               |
| Hoverboard     | Temporary shield           |
